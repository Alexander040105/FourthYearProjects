# MongoDBAct1 Lab 1.0 — Reworked Deliverables

This folder contains the corrected MongoDB data-lake lab deliverables. The original `data_warehousing/MongoDBAct1` folder is left untouched.

## Files

- `01_datalake_setup.mongodb.js` — MongoDB shell script that creates `juanmart_data_lake.raw_checkout_landing` as a capped collection with indexes.
- `02_mongo_driver.py` — Singleton `DataLakeDriver` with connection pooling, timeouts, and config loading.
- `mongo_config.json` — Default connection config.
- `generate_mock_payload.py` — Generates `mock_payload.json` with 1,500 documents.
- `03_raw_ingest_lake.py` — Ingests `mock_payload.json` into `raw_checkout_landing`, adds metadata, and writes `lake_ingest_execution.log`.
- `04_lake_audit_queries.json` — Native MongoDB aggregation pipelines for auditing the landing collection.
- `lake_ingest_execution.log` — Generated by `03_raw_ingest_lake.py`.
- `dry_run_ingest.py` — Optional helper that runs the ingestion against an in-memory `mongomock` instance. Useful when a real `mongod` is not available.

## Test run (no real MongoDB required)

The `lake_ingest_execution.log` in this folder was produced with the mongomock dry-run. To reproduce it:

```powershell
.venv\Scripts\Activate.ps1
python data_warehousing\MongoDBAct1_Reworked\dry_run_ingest.py
cat data_warehousing\MongoDBAct1_Reworked\lake_ingest_execution.log
```

The log will contain exactly the expected format, source counts, and totals.

## Real MongoDB run (when mongod is available)

Once you have a working local MongoDB on `localhost:27017`:

```powershell
.venv\Scripts\Activate.ps1

# Generate or re-generate the payload
python data_warehousing\MongoDBAct1_Reworked\generate_mock_payload.py

# Ingest into the real database
python data_warehousing\MongoDBAct1_Reworked\03_raw_ingest_lake.py

# Check the log
cat data_warehousing\MongoDBAct1_Reworked\lake_ingest_execution.log
```

`03_raw_ingest_lake.py` will create the `raw_checkout_landing` capped collection and indexes automatically if they do not exist.

You can also apply the shell setup script with `mongosh` (once installed):

```powershell
mongosh "C:\Users\Pixel-Tone\Documents\GitHub\FourthYearProjects\data_warehousing\MongoDBAct1_Reworked\01_datalake_setup.mongodb.js"
```

## Note on the local MongoDB issue

The `mongod.exe` installed by the 8.3.7 MSI at `C:\Program Files\MongoDB\Server\8.3\bin\mongod.exe` failed to start with `STATUS_ENTRYPOINT_NOT_FOUND` (`0xC0000139`), even after updating the Visual C++ Redistributable. Because of that, the ingestion was verified using `mongomock`. If you reinstall or repair MongoDB, replace the generated log by running `03_raw_ingest_lake.py` against the real server.
